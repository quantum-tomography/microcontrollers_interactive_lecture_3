Theoretical Foundations

Address Bus

Unidirectional: Sends the address binary word from the CPU to memory. Determines which specific cell (0x00 to 0x0F) will be accessed.

R/W Control Signal

Single Line Connection:
• R/W = 1 (High): Read Operation
• R/W = 0 (Low): Write Operation

Data Bus

Bidirectional: Transfers the byte of data from memory to CPU (during Read) or CPU to memory (during Write).

Memory Capacity Calculator

Formula: $2^N \times M$
Address Bus Lines (N bits): 8 bits (256 cells)
Bits per Memory Cell (M word width): 8 bits (1 Byte)
Total Cells ($2^N$): 256 cells
Total Storage Bits: 2,048 bits
Standard Capacity Unit: 2 Kbit / 256 Bytes
Textbook Example Verification: If memory contains 256 cells of 8 bits each, capacity is $256 \times 8 = 2048 \text{ bits} = 2 \text{ Kbit}$.

Memory Access Time Breakdown

Time elapsed from CPU initial read/write request until operation completion.

Static RAM (SRAM Cache): 1 - 5 ns (Ultra Fast)
Dynamic RAM (DRAM Main Memory): 10 - 50 ns (Fast)
Flash Memory (NAND NVMe): 25,000 ns (Medium)

Key Rule:

Smaller access time equates to higher performance memory. Modern high-speed processors require access times on the order of several nanoseconds (ns) to avoid stalling cycle execution.

Microcontroller Bus Types (Fig. 1.4)

1. Address Bus (Еднопосочна)

Unidirectional lines carrying target cell coordinates from CPU to memory. Higher line count increases max addressable range ($2^N$).

2. Data Bus (Двупосочна)

Bidirectional lines transferring actual payload between CPU, RAM, and peripherals. Bus width dictates immediate bit-width throughput.

3. Program Bus (Програмна)

Transfers instruction codes from flash program memory to CPU. Unified or separate (Harvard vs Von Neumann architecture).

8-bit Data Bus Bottleneck Simulation

16-bit Transfer Test

When an 8-bit CPU needs to transfer a 16-bit word (e.g., 0xABCD), it must split the data and send it over two separate cycles:

REGISTER 0xABCD
Cycle 0: Idle
MEMORY 0x0000
Takeaway: Transferring wider data words over smaller bus widths takes extra time and additional clock cycles, directly impacting execution performance.
